# Docket — UI / 版式约束

> UI 改动的宪法。设计 token 定义在 `src/styles/global.css`（**唯一来源**），本文只写规则与禁则，不重复定义色值。

## 品牌与气质

深底钢笔 D（Dock / 托盘 / 启动画面同一字形）。文书 / 卷宗隐喻可用（事项、办结、依据、指标、轨道），
**不拟物**：不做印章、火漆、纸张纹理。默认克制：内容即主角，装饰退后。

## 强调色规则（核心）

强调色（`--accent`）**只给可交互元素**：按钮、开关、链接、焦点环、选中日期。

- 选中态只用背景（`--bg-selected`）；禁止色条 / 竖条 / 加粗三连
- 反馈（toast、状态标签）用图标 + 文案；**禁止彩色左条**（已修，回归由 e2e 锁定）
- 徽章（缺依据 / 已归档）用中性或语义色，不抢主按钮

## 版式语法

- 页头：24px/700 标题 + 14px 一句说明（全 app 统一，不混三种头）
- 设置 / 管理页：max-width 720px 左对齐卡片（`--bg-elevated` + 边框 + `radius-lg`）
- 卡内行式：左标签（+小字说明）、右控件右对齐、行间细分隔线；主按钮在卡片 footer 右下
- 网格一律 `minmax(0, 1fr)`；列表动作用幽灵字按钮，悬停浮背景
- 按钮文字必须横排完整：容器不够改布局，**不压字不断字**

## 字号与间距

字阶（token）：12 / 13 / 14 / 15 / 17 / 20 / 24。不另起字号。
间距走 4px 节奏（`--space-1..6`）。圆角 / 阴影 / 边框用 token，不取野值；
阴影只给浮层（抽屉、toast、对话框），列表与卡片不用阴影造层次。

## 保存策略（混合）

开关与主题：**自动保存**（toast「已保存」）；带校验的表单：footer「保存」。
开关自动存以**已存快照**为基座合并单字段，不吞未保存的表单草稿。

## 禁则清单

- emoji 当图标 / 装饰
- 印章、拟物、大面积渐变、阴影当层次主语言
- 强调色当背景 / 装饰 / 信息条
- 断词换行的按钮与标签
- 三个头部规格混用；控件裸奔全宽不进卡片（设置类页面）
- 未经 `global.css` 的野生色值 / 字号 / 圆角

## 变更纪律

改视觉语言（token、禁则、版式语法）须先改本文并经用户确认；
日常 UI 改动对照本文自查即可，不写新规则。
