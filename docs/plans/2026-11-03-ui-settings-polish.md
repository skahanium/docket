# UI 收整：设置重组、选中态与版式修复（现行）

权威来源：本文 + 仓库根目录 [README.md](../../README.md) + 代码。壳层见 [2026-11-02-app-shell.md](2026-11-02-app-shell.md)。**状态：已按案施工；技术债清理见「落地时的顺手清理」。**

## 背景与目标

设置九个子页空、散、头部语法分裂；模板编辑步骤卡被挤成一字竖排；侧栏选中项蓝条抢戏。用户已定两原则：**（a）接受 9→6 合并页；（b）保存用混合策略**（开关/主题自动保存，带校验表单留「保存」）。目标是一次整体收整，不加功能。

## 审查结论（病灶与根因）

| # | 病灶 | 根因 |
|---|------|------|
| 1 | 模板步骤「上移/下移/删除」一字一行、「需要依据」断行 | `PlaybookPage` 的 `.step` 是**两列** grid（28px 序号 + 1fr），却塞了**三个**子项：序号、标题 input、（标签+按钮）块。第三块掉进 28px 列 |
| 2 | 选中项蓝条 + 浅底混杂 | `.itemActive` 有 `box-shadow: inset 3px 0 0 var(--accent)`，且 `--bg-active` 是蓝调 |
| 3 | 设置页空、散 | 9 页中 4 页不足 3 个控件；无卡片语法，控件裸奔全宽；头部三种规格（大 H1 / 小节题 / 无题） |
| 4 | 数据页路径断词（`Appl ication`） | `.path` 用 `word-break: break-all` |
| 5 | 列表行「编辑/删除」像禁用态 | 灰字无悬停态 |
| 6 | 保存按钮位置不一（左下/右上/横排） | 无统一 footer 位 |

主页面（今日/任务/事项/日历/进展）上一波已做过挤扁修复；本轮只做**审查确认**，发现新病灶再列，不主动重构。

## 视觉总原则

- 强调色只留给**可交互**：按钮、开关、链接、焦点环。选中态**只用背景**（新 token `--bg-selected`：浅 `#EAEAEA` / 深 `#2A2A2A`，比 hover 重一级）。
- 版式语法统一：每页「24px 大标题 + 一句说明」；内容进 **max-width 720px** 左对齐卡片（`--bg-elevated` + 边框 + `radius-lg`）；卡内**行式**：左标签（+小字说明），右控件右对齐，行间细分隔线。
- 动作位统一：主按钮放**卡片 footer 右侧**；列表动作用幽灵字按钮，悬停浮现背景。

## 方案

### A. 选中态收敛（小）

`.itemActive` 去掉蓝条与加粗，只保留 `background: var(--bg-selected)` + 正文字色。作用于主侧栏与设置导航（共用 `Sidebar.module.css`）。`--bg-active` 保留给其他用途不动。

### B. 设置 9 → 6 页 + 卡片语法 + 混合保存

**页面合并**：

| 新页 | 内容（卡片） | 来源 |
|------|------------|------|
| 常规 | 外观（主题三键）/ 工作时间（上午·下午·默认专注）/ 节假日（缓存数 + 同步） | 原 常规+外观+节假日 |
| 提醒与面板 | 通知（摘要/逾期）/ 桌面面板（置顶/不透明/刷新） | 原 通知+桌面面板 |
| 分类 | 列表管理（不动） | 原 分类 |
| 标签 | 列表管理（不动） | 原 标签 |
| 模板 | 模板管理 + 步骤编辑（见 C） | 原 模板 |
| 数据 | 数据与备份（路径 + 三按钮） | 原 数据 |

**卡片内的行式示例（工作时间卡）**：

```
工作时间                                    [卡标题]
  上午                      [08:30] – [12:00]
  下午                      [14:30] – [18:00]
  默认专注                         [45] 分钟
  ─────────────────────────────────────────
                                    [保存]   ← footer 右对齐
```

**保存策略矩阵（混合）**：

| 控件 | 策略 |
|------|------|
| 主题三键 | 自动保存（已如此，保留） |
| 工作时间 4 格 + 默认专注 | 表单 + footer「保存」（有校验） |
| 每日摘要 / 逾期提醒 开关 | 自动保存（单字段落库，toast「已保存」） |
| 摘要时间 / 逾期间隔 | 表单 + footer「保存通知设置」（有校验） |
| 桌面面板 置顶 / 不透明 开关 | 自动保存（单字段落库） |
| 刷新间隔（30–600） | 表单 + footer「保存面板设置」（有校验） |
| 节假日同步 | 按钮即动作（确认后联网） |

自动保存的开关以**已保存快照**为基座合并单字段，不吞未保存的表单草稿。

### C. 模板编辑器修复（病灶 1）

步骤卡改为**两子项**（序号 `.stepMark` + `.stepBody`），体内两行：标题 input 一行；第二行左「需要依据」勾选、右「上移/下移/删除」横排。复用 `MatterDetail` 步骤的 `.step` 网格，不再另造。加一步/保存步骤/完成 三键放编辑区 footer。

### D. 零散打磨

- 数据页路径：单行 `text-overflow: ellipsis` + `title` 挂完整路径，不再断词；三按钮放 actions 行。
- 分类/标签/模板列表行「编辑/删除」：幽灵字按钮，悬停背景+主字色。
- 各设置页头部统一「大标题 + 一句说明」；模板编辑「编辑：xxx」改为卡标题。
- 禁用按钮透明度统一 0.45；主按钮 hover 不闪白。

### E. 主页面审查范围

只**确认**：今日/任务/事项/日历/进展 + 桌面面板的布局无挤扁/断字/三种头部。发现才修，不重排。
