# 五视图壳层与设置浮层（现行）

权威来源：本文 + 仓库根目录 [README.md](../../README.md) + 代码。对象模型仍以 [2026-10-29-matters-playbooks-cadences.md](2026-10-29-matters-playbooks-cadences.md) 为准。`docs/superpowers/` 为历史稿，不描述本壳层。

## 主壳

侧栏五条轨道，启动默认 **今日**：

| 视图 | `ViewKind` | 内容 |
|------|------------|------|
| 今日 | `today` | 并行 `list_agenda('overdue')` 与 `list_agenda('today')`，列表两段「逾期 / 今日」；皆空则为「暂无安排」 |
| 任务 | `tasks` | 原任务库；标题旁「看归档」（本地 `list_archived`，不占 ViewKind） |
| 事项 | `matters` | 事项库，对象模型不变 |
| 日历 | `calendar` | 月格 + 点日；选中日后下方为当天任务列表（只筛任务）+ 受控排程（只排任务）。离开日历卸载时清除 `selectedDate`；`due_date` 只在日历视图写入 `list_tasks` |
| 进展 | `progress` | 一页下滚：统计面板 + 周期指标 |

设置**不占** `ViewKind`。侧栏底部居中齿轮打开浮层，主壳 `inert`；点遮罩或 Esc 先关设置，回到进入前的视图。Esc 顺序：设置 → 新建/复盘 → 详情。

分类 / 标签只在侧栏筛选，无「管理」。顶栏太阳仍是主题快捷切换；设置 → 外观也可改主题。主栏与设置右栏的库页（事项、模板、指标、分类、标签）是通栏列表，不贴左缩成一排。侧栏右缘可拖 200–360px，且不得把主栏挤到 480px 以下；主栏按自身宽度做容器查询（统计卡片、日历格、内边距），详情抽屉 `max-width` 不超过「窗口 − 侧栏」，避免盖住侧栏。

## 设置浮层子页

常规、外观（日间 / 夜间 / 跟随系统）、通知、桌面面板、分类、标签、模板、节假日、数据。

新建对话框仍可选模板。模板编辑在设置，不在侧栏。

## 资源拉取

- 今日：两条议程；不用任务列表的 `today_view` / `overdue_view`
- 任务库：`list_tasks`（active）；归档为列表本地开关
- 日历：仅该视图拉月数据；有选中日才拉当天任务；排程日期 = 选中日
- 进展：`get_stats_panel`；指标在此页定义，不进今日
- 模板 / 指标：进展、事项、设置打开、或已选中事项时拉取

## 非目标

事项步进排程/专注、今日挂指标、搜索进事项库、改绑/拖期/删步手测、新配色、改写 `docs/superpowers/`。
