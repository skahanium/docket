# 五视图壳层与设置浮层（现行）

权威来源：本文 + 仓库根目录 [README.md](../../README.md) + 代码。对象模型仍以 [2026-10-29-matters-playbooks-cadences.md](2026-10-29-matters-playbooks-cadences.md) 为准。`docs/superpowers/` 为历史稿，不描述本壳层。

## 主壳

侧栏五条轨道，启动默认 **今日**：

| 视图 | `ViewKind` | 内容 |
|------|------------|------|
| 今日 | `today` | 并行 `list_agenda('overdue')` 与 `list_agenda('today')`，列表两段「逾期 / 今日」；皆空则为「暂无安排」 |
| 任务 | `tasks` | 原任务库；标题旁「看归档」（本地 `list_archived`，不占 ViewKind） |
| 事项 | `matters` | 事项库，对象模型不变 |
| 日历 | `calendar` | 月格 + 点日；选中日后下方为当天任务列表（只筛任务）+ 受控排程（只排任务）。离开日历卸载时清除 `selectedDate`；`due_date` 只在日历视图写入 `list_tasks` |
| 进展 | `progress` | 一页下滚：统计面板 + 周期指标 |

设置**不占** `ViewKind`。侧栏底部居中齿轮打开浮层，主壳 `inert`；点遮罩或 Esc 先关设置，回到进入前的视图。Esc 顺序：设置 → 新建/复盘 → 详情。

分类 / 标签与五条轨道是**同一级目的地**，不是今日 / 任务 / 事项上的页内筛选。点侧栏某一分类或标签即离开当前轨道，进入标题为该名称的独立页，**同时**列出此分类（或标签）下的今日安排、任务、事项；日历与进展不进这一页。分类与标签互斥，一次只打开其中一个。点回五条轨道则离开该页，任务库 / 事项库恢复全量（不再被侧栏分类染色）。再点当前已打开的分类或标签：留在该页。设置里被删且正打开该项时回到今日。该页不提供「看归档」、排序、优先级下拉。导航状态用 `openFacet: { type: 'category' | 'tag'; id: number } | null`，不把 `ViewKind` 扩成第六项；点轨道时清掉 `openFacet`。

顶栏太阳仍是主题快捷切换；设置 → 外观也可改主题。主栏与设置右栏的库页（事项、模板、指标、分类、标签）是通栏列表，不贴左缩成一排。侧栏右缘可拖 200–360px，且不得把主栏挤到 480px 以下；主栏按自身宽度做容器查询（统计卡片、日历格、内边距），详情抽屉 `max-width` 不超过「窗口 − 侧栏」，避免盖住侧栏。

## 设置浮层子页

常规、外观（日间 / 夜间 / 跟随系统）、通知、桌面面板、分类、标签、模板、节假日、数据。

新建对话框仍可选模板。模板编辑在设置，不在侧栏。

## 资源拉取

- 今日：两条议程；不用任务列表的 `today_view` / `overdue_view`；今日页本身不再吃侧栏分类 / 标签
- 任务库：`list_tasks`（active），**不**把分类 / 标签写进筛选；归档为列表本地开关
- 日历：仅该视图拉月数据；有选中日才拉当天任务；排程日期 = 选中日；`due_date` 不泄漏到任务库或分类 / 标签页
- 进展：`get_stats_panel`；指标在此页定义，不进今日
- 分类 / 标签页：自行拉 `list_agenda('today'|'overdue')`（再按 `categoryId` / `tagId` 过滤）、`list_tasks({ status: 'active', category_id | tag_id })`、`list_matters()`（客户端按分类 / 标签过滤）；事项列表 IPC 仍无筛参
- 模板 / 指标：进展、事项、设置打开、已选中事项、或分类 / 标签页打开时拉取模板

## 非目标

事项步进排程/专注、今日挂指标、搜索进事项库、分类∩标签叠筛、日历/归档进分类页、改绑/拖期/删步手测、新配色、改写 `docs/superpowers/`。
